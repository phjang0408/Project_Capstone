# 확인한 구현과 검증 범위

기준일: 2026.09.22. 최종보고서, 공개 C++ 소스, 공유 ZIP 파일 목록을 대조했습니다. 게임 실행·서버 연결·성능 측정을 새로 수행한 결과는 아닙니다.

## 자료 간 차이와 해석

| 항목 | 확인 내용 | 문서화 기준 |
| --- | --- | --- |
| 게임 호스팅 | 보고서는 Dedicated Server, C++는 `Lobby?listen` | 공개 코드 버전은 Listen Server 흐름으로 설명 |
| 공유 인벤토리 | 보고서는 공유 동작을 기록, C++ 배열에는 `Replicated` 없음 | Blueprint를 포함한 전체 구현은 추가 확인 필요 |
| AI 입력 | 보고서는 최대 200자, C++ `SendAIQuestion`에는 길이 검증 없음 | UI 사양으로만 소개하며 보안 방어 구현으로 단정하지 않음 |
| 성능·가용성 | 60 FPS·3초·99% 등은 요구사항과 완성도 표에 기재 | 측정 환경과 원시 결과가 없어 실측 성과로 사용하지 않음 |
| 프로젝트 시점 | 표지는 2025학년도 2학기, 제약 표에는 2024년 문구 | 보고서 작성일만 명시하고 정확한 개발 기간은 단정하지 않음 |
| SW 등록 | 접수증·신청서·수수료 영수증 첨부 | 등록 완료나 수상 실적으로 기재하지 않음 |

## 재현을 위해 필요한 자료

- 원본 `.uproject`, `Config`, `Content`와 사용한 엔진 버전
- Blueprint의 RPC 호출 주체, 공유 인벤토리 및 UI 갱신 경로
- 배포본에 맞는 백엔드·AI 서버 설정과 실행 가능한 API 계약
- 실제 참가자 수, 시험 환경, 성능 측정 원본

## 후속 코드 개선 지점

1. **통신 계약 정리:** 하드코딩된 서버 URL을 설정으로 분리하고 `/api` 접두어·요청 필드·응답 스키마를 통일합니다.
2. **응답 처리 강화:** `bWasSuccessful` 외에 HTTP 상태 코드와 응답 포인터, 필수 필드 타입을 확인합니다.
3. **호출 권한 확인:** GameState의 Server RPC를 어떤 객체가 요청하는지 검토하고 서버 권한을 가진 경로에서 처리하도록 정리합니다.
4. **로그 정리:** 현재 소스의 인증 티켓·토큰·원문 응답 출력 코드를 제거하거나 마스킹합니다.
5. **동기화 경로 문서화:** 인벤토리·문 상태·채점 UI에 대해 서버와 클라이언트 각각의 갱신 흐름을 확인합니다.

이 항목들은 소스 검토에서 확인한 후속 과제이며, 이번 문서 보완에서 수정하거나 해결한 것으로 표시하지 않습니다.
